# CLAUDE.md: Cardforge

CardForge: drag-and-drop Rush Q card designer; schema-aware editor, live preview, export/import cards.json + copy-to-clipboard (cardforge.neorgon.com)

**Live:** cardforge.neorgon.com · **Port:** 8851

## Run

```bash
make serve
```

Then open http://localhost:8851. It must be served over HTTP. The app is ES modules, and `file://` blocks them.

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- The fleet guideline is ~500 lines per module; `js/template-editor.js` is already past it. Split when touching it, do not grow it further.
